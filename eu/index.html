Aplikazio bakarra bosten ordez

Webguneak egitea fitxategi-bezero, datu-base tresna, terminal, Git eta API probatzaile baten artean aldatzea da. Hopperrek dena batera du: zauden zerbitzaria editatzen ari zaren datu-basea ere bada.

  • Fitxategi-transferentziaFTP, FTPS eta SFTP
  • Datu-baseakMySQL, MariaDB, PostgreSQL, SQLite
  • SSH terminalaFitxak, pantaila zatitua, snippetak
  • GitCommit, push, pull eta hedapena
  • API eskaerakBildumak, inguruneak, cURL

Mugitu fitxategiak pentsatu gabe

Karpeta lokala eta urrunekoa elkarren ondoan. Arrastatu eta utzi, eta Hopperrek egingo du gainerakoa: transferentzia paraleloak, gatazkak eta gelditutako lekutik berrekitea.

  • Editatu urruneko fitxategiak eta gordetzean igotzen dira
  • Gainidazten duzun fitxategi bakoitzaren kopia, egun batez gordeta
  • Abisatzen dizu helburuko karpeta okerra dirudienean
  • Sinkronizatu bi karpeta desberdintasunak aurretik ikusita

Taula handiekin arina den datu-base bezeroa

Lehen errenkadak berehala agertzen dira eta gainerakoak atzeko planoan kargatzen dira. Editatu gelaxkak, iragazi, ordenatu eta esportatu, produkzioko datu-baseak lehenespenez babestuta.

  • Erlazionatutako tauletako balio iradokiak
  • Data-eremuetarako egutegia orduarekin
  • Desegin, berregin eta gorde aurretik berrikusi
  • SSH tunelak, egituren konparazioa eta erlazio-diagrama

Probatu zure APIa zerbitzariaren ondoan

Bildumak, inguruneak eta Giltzatakoan gordetako aldagai sekretuak. Itsatsi cURL agindu bat eta Hopperrek beteko dizu eskaera.

  • JSON, XML, formularioak, fitxategiak eta GraphQL
  • Bearer, oinarrizko eta API key autentifikazioa
  • Kopiatu cURL, fetch, Python edo HTTPie gisa
  • Erantzun bakoitzaren denborak, cookieak eta goiburuak

Galderak

Doako bertsioa benetan doakoa da?

Bai. Ez da iraungitzen eta ez da proba bat. Gordetako zerbitzari, datu-base eta eskaeren muga du, eta tresna profesional batzuk Prorenak dira.

Zer dut Prorekin?

Gordetako konexio mugagabeak, karpeten sinkronizazioa, Gitetik hedatzea, egituren konparazioa, erlazio-diagrama eta zerbitzariaren tresnak. Behin ordaintzen duzu eta duzun bertsioa betiko da zurea.

Nola aktibatzen dut lizentzia?

Erosi ondoren gako bat jasoko duzu posta elektronikoz. Hopperren, ireki Ezarpenak, gero Lizentzia, itsatsi gakoa eta sakatu Aktibatu.

Mac batean baino gehiagotan erabil dezaket?

Bai, lizentzia bakoitzak bi Mac-etan funtzionatzen du. Mac batean desaktibatu dezakezu beste batera eramateko.

Non gordetzen dira pasahitzak?

macOS-eko Giltzatakoan. Hopperrek ez ditu inoiz pasahitzak bere konfigurazio-fitxategietan idazten, eta ekintza delikatuak Touch IDrekin babes ditzakezu.

Zein datu-base onartzen ditu?

MySQL, MariaDB, PostgreSQL eta SQLite, zuzenean edo SSH tunel baten bidez.
