Tus servidores, bases de datos y APIs en una sola ventana

Hopper es la app de Mac para quien hace webs. Sube archivos, edita tablas, ejecuta comandos y prueba endpoints sin ir saltando entre cinco herramientas distintas.

Arrastra archivos entre el Mac y el servidor. Las transferencias van en paralelo y puedes pausarlas y reanudarlas.

Una sola app en lugar de cinco

Hacer webs significa cambiar entre un cliente de archivos, una herramienta de bases de datos, un terminal, Git y un probador de APIs. Hopper lo tiene todo junto: el servidor en el que estás es también la base de datos que editas.

  • Transferencia de archivosFTP, FTPS y SFTP
  • Bases de datosMySQL, MariaDB, PostgreSQL, SQLite
  • Terminal SSHPestañas, pantalla dividida, snippets
  • GitCommit, push, pull y despliegue
  • Peticiones de APIColecciones, entornos, cURL

Mueve archivos sin pensarlo

Las carpetas local y remota una al lado de la otra. Arrastra y suelta, y Hopper se encarga del resto: transferencias en paralelo, conflictos y reanudar donde se había parado.

  • Edita archivos remotos y se suben al guardar
  • Una copia de cada archivo que sobrescribes, guardada un día
  • Te avisa si la carpeta de destino parece equivocada
  • Sincroniza dos carpetas viendo antes las diferencias

Un cliente de bases de datos ágil con tablas grandes

Las primeras filas aparecen al instante y el resto se carga en segundo plano. Edita celdas, filtra, ordena y exporta, con las bases de datos de producción protegidas por defecto.

  • Valores sugeridos de las tablas relacionadas
  • Calendario con hora para los campos de fecha
  • Deshacer, rehacer y revisión antes de guardar
  • Túneles SSH, comparación de estructuras y diagrama de relaciones

Prueba tu API junto a tu servidor

Colecciones, entornos y variables secretas guardadas en el Llavero. Pega un comando cURL y Hopper te rellena la petición.

  • JSON, XML, formularios, archivos y GraphQL
  • Autenticación Bearer, básica y API key
  • Copia como cURL, fetch, Python o HTTPie
  • Tiempos, cookies y cabeceras de cada respuesta

Preguntas

¿La versión gratuita es gratis de verdad?

Sí. No caduca y no es una prueba. Tiene un límite de servidores, bases de datos y peticiones guardados, y algunas herramientas profesionales son de Pro.

¿Qué tengo con Pro?

Conexiones guardadas sin límite, sincronización de carpetas, despliegue desde Git, comparación de estructuras, el diagrama de relaciones y las herramientas del servidor. Pagas una vez y la versión que tienes es tuya para siempre.

¿Cómo activo la licencia?

Después de comprar recibirás una clave por correo. En Hopper, abre Ajustes, luego Licencia, pega la clave y pulsa Activar.

¿Puedo usarla en más de un Mac?

Sí, cada licencia funciona en dos Macs. Puedes desactivarla en un Mac para pasarla a otro.

¿Dónde se guardan las contraseñas?

En el Llavero de macOS. Hopper nunca escribe contraseñas en sus archivos de configuración, y puedes proteger las acciones delicadas con Touch ID.

¿Qué bases de datos admite?

MySQL, MariaDB, PostgreSQL y SQLite, directamente o a través de un túnel SSH.
