One app instead of five

Most web work means switching between a file client, a database tool, a terminal, Git and an API tester. Hopper keeps them together, so the server you're on is also the database you're editing.

  • File transfersFTP, FTPS and SFTP
  • DatabasesMySQL, MariaDB, PostgreSQL, SQLite
  • SSH terminalTabs, split view, snippets
  • GitCommit, push, pull and deploy
  • API requestsCollections, environments, cURL

Move files without thinking about it

Local and remote folders side by side. Drag, drop, and Hopper takes care of the rest: parallel transfers, conflicts, and resuming where it stopped.

  • Edit remote files and they upload when you save
  • A copy of every file you overwrite, kept for a day
  • Warns you when the destination folder looks wrong
  • Sync two folders and see the differences first

A database client that's fast with big tables

The first rows appear right away and the rest load in the background. Edit cells, filter, sort and export, with production databases protected by default.

  • Suggested values from related tables
  • Date and time picker for date columns
  • Undo, redo and a review before saving
  • SSH tunnels, schema diff and relationship diagram

Test your API next to your server

Collections, environments and secret variables stored in the Keychain. Paste a cURL command and Hopper fills in the request for you.

  • JSON, XML, forms, file uploads and GraphQL
  • Bearer, Basic and API key authentication
  • Copy as cURL, fetch, Python or HTTPie
  • Timing, cookies and headers for every response

Questions

Is the free version really free?

Yes. It doesn't expire and it isn't a trial. It has limits on how many servers, databases and requests you can save, and a few professional tools are part of Pro.

What do I get with Pro?

No limits on saved connections, plus folder sync, deploy from Git, schema diff, the relationship diagram and the server tools. You pay once and keep the version you have forever.

How do I activate my license?

After buying you'll get a license key by email. In Hopper, open Settings, then License, paste the key and press Activate.

Can I use it on more than one Mac?

Yes, each license works on two Macs. You can deactivate it on one Mac to move it to another.

Where are my passwords stored?

In the macOS Keychain. Hopper never writes passwords to its configuration files, and you can protect sensitive actions with Touch ID.

Which databases does it support?

MySQL, MariaDB, PostgreSQL and SQLite, directly or through an SSH tunnel.
