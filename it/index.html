Scarica

I tuoi server, database e API in un'unica finestra

Hopper è l'app per Mac di chi crea siti web. Carica file, modifica tabelle, esegui comandi e prova endpoint senza saltare tra cinque strumenti diversi.

Scarica per Mac Vedi i prezzi

macOS 12 o successivo · Apple Silicon e Intel · La versione gratuita non scade

Trascina file tra il Mac e il server. I trasferimenti vanno in parallelo e puoi metterli in pausa e riprenderli.

Un'unica app al posto di cinque

Fare siti web significa passare da un client di file a uno strumento per database, un terminale, Git e un tester di API. Hopper tiene tutto insieme: il server su cui sei è anche il database che modifichi.

  • Trasferimento fileFTP, FTPS e SFTP
  • DatabaseMySQL, MariaDB, PostgreSQL, SQLite
  • Terminale SSHSchede, schermo diviso, snippet
  • GitCommit, push, pull e deploy
  • Richieste APIRaccolte, ambienti, cURL

Sposta file senza pensarci

Cartelle locale e remota affiancate. Trascina e rilascia, Hopper pensa al resto: trasferimenti paralleli, conflitti e ripresa da dove si era fermato.

  • Modifica file remoti e vengono caricati al salvataggio
  • Una copia di ogni file sovrascritto, conservata un giorno
  • Ti avvisa se la cartella di destinazione sembra sbagliata
  • Sincronizza due cartelle vedendo prima le differenze

Un client per database veloce con le tabelle grandi

Le prime righe compaiono subito e il resto si carica in background. Modifica celle, filtra, ordina ed esporta, con i database di produzione protetti per impostazione predefinita.

  • Valori suggeriti dalle tabelle collegate
  • Calendario con ora per i campi data
  • Annulla, ripeti e revisione prima di salvare
  • Tunnel SSH, confronto strutture e diagramma delle relazioni

Prova la tua API accanto al server

Raccolte, ambienti e variabili segrete salvate nel Portachiavi. Incolla un comando cURL e Hopper compila la richiesta per te.

  • JSON, XML, moduli, file e GraphQL
  • Autenticazione Bearer, Basic e API key
  • Copia come cURL, fetch, Python o HTTPie
  • Tempi, cookie e intestazioni di ogni risposta

Domande

La versione gratuita è davvero gratuita?

Sì. Non scade e non è una prova. Ha un limite di server, database e richieste salvati, e alcuni strumenti professionali fanno parte di Pro.

Cosa ottengo con Pro?

Connessioni salvate illimitate, sincronizzazione cartelle, deploy da Git, confronto strutture, diagramma delle relazioni e strumenti del server. Paghi una volta e la versione che hai resta tua per sempre.

Come attivo la licenza?

Dopo l'acquisto riceverai una chiave via email. In Hopper apri Impostazioni, poi Licenza, incolla la chiave e premi Attiva.

Posso usarla su più di un Mac?

Sì, ogni licenza funziona su due Mac. Puoi disattivarla su un Mac per spostarla su un altro.

Dove vengono salvate le password?

Nel Portachiavi di macOS. Hopper non scrive mai password nei suoi file di configurazione, e puoi proteggere le azioni delicate con Touch ID.

Quali database supporta?

MySQL, MariaDB, PostgreSQL e SQLite, direttamente o tramite tunnel SSH.
